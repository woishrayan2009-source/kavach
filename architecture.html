System Design

Eight modules. One hub. One cascade.

Every sensor below is well-studied on its own — fire detection, fall detection, ambulance routing, and the rest are each individually solvable problems. What isn't already solved is the layer underneath: getting all eight to report into one dashboard and escalate through one shared alert chain instead of eight disconnected ones.

The actual contribution

Fire scanning, fall detection, ambulance routing — each of these hazards is already well-studied in isolation, and plenty of standalone gadgets exist for each one. What's new in Kavach isn't any single sensor; it's the grid layer above them. Every module, whether it's shipped hardware like Extingo, a live software demo like Rakshak and Sanjeevani, or a reasoned concept like the four hazard modules still on paper, reports into the same dashboard and triggers the same four-step escalation — so a family or institution manages one safety system, not eight.
